The inspector's first section is now a tabbed panel with Files, Git, Search, and Actions pages, switchable from icon tabs or Cmd+Shift+1–4.

- New Files tab shows the whole workspace as a tree (gitignored files hidden), with edited files and their folders tinted yellow; clicking opens the file in the editor.
- New Search tab searches file contents across the workspace with case, whole-word, regex, and include/exclude filters — plus bulk replace across files.
- Git changes open as a reusable preview tab (VS Code style); with the list focused, Up/Down arrows step through changes and Enter pins the tab. List view is now the default.
- Actions moved from its own collapsible section into a panel tab.
